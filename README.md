# Real-Time Expense Tracker with Dashboard

**Minor Project (5th Semester) — Data Analysis using Python**

## Problem Statement
Ek aam vyakti apna daily/monthly kharcha track nahi kar pata, jisse pata nahi chalta ki paisa kaha zyada ja raha hai. Ye project ek simple tool banata hai jisme user apna expense real-time add kar sakta hai, aur system usse category-wise aur month-wise analyze karke charts ke through dikhata hai.

## Tools & Technologies Used
- **Python** — core logic
- **Pandas** — data storage, cleaning, grouping
- **Matplotlib** — visualization (Pie Chart, Bar Chart)
- **CSV file** — as a simple database (expenses.csv)

## Features
1. Add new expense (Date, Category, Amount, Note) — real-time entry
2. View all expenses
3. View total expense
4. Category-wise breakdown with Pie Chart
5. Monthly trend with Bar Chart
6. Top spending category
7. Full Dashboard (Pie + Bar chart together)

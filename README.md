# Spam Detection Project

This project uses Machine Learning to classify messages/emails as either **Spam** or **Ham** (Legitimate).

## 📁 Project Structure
- `code.ipynb`: Main Jupyter Notebook containing data preprocessing, model training, and evaluation.
- `spam.csv`: Dataset used for training and testing.
- `vectorizer.pkl`: Saved TF-IDF Vectorizer model.
- `spam_model.pkl`: Saved Machine Learning model.
- `spam_ham_distribution.png`: Visualization of dataset class distribution.
- `Confusion_matrix.png`: Model performance confusion matrix graph.

## 🚀 How to Run
1. Open `code.ipynb` in Jupyter Notebook.
2. Run all cells to see data preprocessing, model training, and predictions.

## 📊 Results
- Includes distribution plots and a confusion matrix to evaluate classification performance.
